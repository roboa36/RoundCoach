# RoundCoach

VALORANTの試合データを活用し、自分のプレイを客観的に振り返るためのWebアプリです。

試合結果を見るだけではなく、重要なラウンドや改善点を分かりやすく表示し、
「次の試合で何を意識すればよいか」を見つけやすくすることを目的に制作しました。

---

## 制作背景

VALORANTをプレイする中で、自分の実力が伸び悩んだ時期がありました。

試合後に振り返りをしても、感覚だけでは改善点を見つけにくく、
既存の戦績確認サービスでも、成績を見ることはできても
「次に何を改善すればよいのか」が分かりにくいと感じました。

そこで、試合データを活用して自分のプレイを客観的に分析し、
改善につなげられる仕組みとしてRoundCoachを制作しました。

---

## 主な機能

### 試合データの確認

最近の試合を一覧で表示し、勝敗や各種戦績を確認できます。

### 試合ごとの分析

試合を選択すると、その試合のデータをもとに詳しい分析結果を表示します。

### 重要なラウンドの抽出

試合の中から、振り返る価値の高いラウンドを見つけやすくします。

### 試合内容の可視化

マップ上にキル位置などを表示し、
ラウンド内で起きたことを視覚的に確認できます。

## システム構成

基本的なデータの流れは以下のようになっています。

```text
ユーザー
  ↓ 操作
RoundCoach（ブラウザ）
  ↓ JavaScriptからリクエスト
api.php
  ↓
HenrikDev API
  ↓ 試合データ（JSON）
api.php
  ├─ キャッシュ処理
  ├─ データの整理
  └─ 試合・ラウンド分析
  ↓ JSON
JavaScript
  ├─ 表示用の集計・加工
  └─ 画面更新
  ↓
分析結果を表示
```

HenrikDev APIから取得した試合データをapi.phpで整理・分析し、
JSON形式でブラウザ側へ返します。

JavaScriptでは受け取ったデータの表示用の集計や加工を行い、
分析結果を画面に反映します。

## 工夫した点

### APIキーをサーバー側で管理

APIキーがブラウザ側から直接見えないように、
`config.php` と `api.php` を利用してサーバー側で管理しています。

実際のAPIキーを含む `config.php` はGitHubには公開していません。

### APIリクエスト数の削減

外部APIへの不要なリクエストを減らすため、

- 試合データを20試合ずつ段階的に取得
- 必要な場合のみ追加データを取得
- 同じデータはキャッシュして再利用
- 試合詳細は必要になった時に取得

といった方法を採用しています。

### 公開環境に合わせてPHPへ移植

開発初期はNode.jsを利用していましたが、
実際にWeb上で公開する際のサーバー環境に合わせて、
サーバー側の処理をPHPへ移植しました。

## 設定ファイルについて

APIキーなどの設定は `config.php` で管理します。

リポジトリ内の

```text
config.example.php
```

を

```text
config.php
```

という名前でコピーし、HenrikDev APIのキーを設定します。

`config.php` は `.gitignore` に登録しているため、
GitHubには反映されません。
